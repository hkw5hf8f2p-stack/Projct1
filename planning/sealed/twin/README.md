# Фікстура-двійник «Пасіка Верховина» (G0-15)

Статичний український магазин (HTML/CSS, мінімум JS, без зовнішніх ресурсів) з 10 навмисними дефектами SPEC §53.
Перелік — у `EXPECTED.json`.

## Як віддати
Будь-який статичний сервер з кореня цієї теки, напр.:

    cd planning/sealed/twin && python3 -m http.server 8080

Точка входу: `http://localhost:8080/index.html`. Перевіряти на 1440×1000 і 390×844.

## Запечатування
Фікстура запечатана до git-тега заморожування детекторів: до тега її не відкривають детекторним інженерам і не
правлять; SHA-256 записано в `planning/sealed/twin.sha256` (поза текою). Після тега — розкриття, набір не використовується повторно.
Хеш: `cd planning/sealed/twin && find . -type f | LC_ALL=C sort | xargs sha256sum | sha256sum`.
